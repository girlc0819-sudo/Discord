# Audio files

Put audio files for `/play` in this folder. Supported extensions: AAC, FLAC,
M4A, MP3, OGG, Opus, and WAV. The bot lists available files as you type the
`/play` command.

Add your own 10-second intro as `intro.mp3`. It plays when the bot joins a voice
channel and when a member joins a voice channel the bot is already in.

Only add audio you have permission to use. This folder is intended for the
server owner to provide audio files.
